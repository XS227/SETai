How the lines are calculated

Lines 1 & 2

Learned AI selections

A small regularised logistic model learns how recent frequency, long-run frequency and time since the last appearance relate to earlier results. It converts these signals into number weights and samples a valid line. AI 2 uses the same model with a different fixed random seed.

The date and model version fix the random seed. AI 2 is another sample, not a second independently validated model.

Calendar

Day-of-month hypothesis

Reduce the target day of the month to 1–9. Among the latest 400 earlier draws, count numbers from days with that same root. Add the equivalent of 20 draws of smoothed full-history frequencies, then sample without replacement.

History

Previously unseen main set

Sample uniformly, rejecting an exact main-number set if it already appears in the available archive. This changes the filter, not the chance of any remaining individual combination.

Numerology

Date and sum-root hypothesis

Add all digits of the full target date and reduce to 1–9. For earlier dates with that root, find the most common main-number sum root (lowest root breaks a tie). Sample a uniform line until its main-number sum has that root.

Control

Uniform random line

Choose every main set with equal probability, with a separate uniform Viking number. This control is recorded alongside the other methods so comparisons include ordinary chance.

Reproducible

Frozen before the draw

Each registered line includes its creation timestamp, target date, method version and last known draw date. Results are attached afterwards. Local edits and personal lines are not claimed as registered forecasts.

Questions

What is special about AI selection 2?

It uses the same learned probability weights as AI 1, with a different deterministic sample. Frequent numbers are a little more likely to be selected when the fitted weights favour them. The output remains a guess; two hits do not prove the method works.

Why separate the two games?

The pools, schedules and jackpot odds differ. Lotto’s bonus is drawn, while Vikinglotto’s Viking number is chosen. Historical data and model results stay separate.

Can numerology predict a lottery draw?

This lab treats numerology as an exploratory hypothesis. A fair lottery draw is independent of dates, birthdays and earlier results. The lab reports counts and keeps a forward record so any claim can be checked.
