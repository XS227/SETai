05 / Landed cost model

Pris- og marginkalkulator

Regn på et konkret tilbud. Tomme felt er bevisste: ingen fabrikkpris er verifisert. Kalkulatoren legger ikke inn skatter eller valutakurs automatisk.

Varekostnad + frakt / m²—USD per m² før avgifter
Samlet kostnad—USD, ekskl. toll / skatt / retur
Provisjon på vareverdi—USD, kun dersom prosentsats er fylt inn
Importmva 24 % på vare + frakt—USD · kontantbehov ved innførsel
Totalt kontantbehov ved import—USD · inkl. importmva
Kontantutlegg per m²—USD/m² · inkl. importmva

Kalkulatoren forutsetter keramiske fliser i HS 6907 med 0 % ordinær toll og 24 % importmva; «frakt + forsikring» inngår i CIF. Lokal håndtering legges til etter beregnet importmva og kan selv være mva-pliktig som tjeneste. Dette er en forenkling; islandsk tollmyndighet fastsetter endelig avgift. Inngående importmva kan være fradragsberettiget for registrerte virksomheter. Se også tidligere KASHI-markedsanalyse ↗

Provisjon beregnes her på fabrikkens vareverdi for å illustrere en modell — dette er ikke en avtalt utbetalingsbase. Reell fortjeneste og salgspris krever valutakurs, islandske avgifter, betalingsgebyrer, svinn, retur og kontraktsvilkår. Verdiene sendes ikke til en server.
