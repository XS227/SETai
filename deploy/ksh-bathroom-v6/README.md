# KSH shared bathroom v6

Lossless Y-up root transform for Vedum, Z-UP and Althea GLBs. Corrected binaries receive a new URL, so old browser caches cannot preserve the sideways models. Legacy and corrected files are both supported by the shared room normalizer; double rotation is rejected by the root marker.

All four product pages link to `/ksh/fliskonkurrenten/showroom/?add=PRODUCT`. The same room module and `ksh-bathroom-v6` state are also used by the existing Sense inline room. Product selections, dimensions, finish and live subtotal persist across these entrances. Original product photos remain authoritative references. Stone is a photo reference with no invented price or 3D asset.

Run `node bathroom-v6/test-models.mjs` from the source workspace to verify actual GLB bounds and placement at three room sizes. Browser controls and price changes were exercised; the test browser has WebGL disabled, so rendered WebGL appearance is not visually certified here.

3D Jutsu project: https://higgsfield.ai/3d-jutsu/6ea2fb1d-40be-4264-a624-68f640bc997f
The cinema scene is a procedural visual reconstruction based on the Vedum reference, not factory CAD or scanned supplier textures. Keep that distinction in any client presentation.

The installer validates all payload hashes, prepares all replacements before writing, backs up existing files, and rolls back interrupted writes. New-file manifest is stored with the backup. Requires the existing KSH v6 / Sense film deployment. Repeated installs reuse the canonical source and do not accumulate transforms.
