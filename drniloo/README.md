# پروژه DrNiloo

این پوشه نسخه اولیه پروژه وب و سئوی دکتر نیلوفر غفوری است و برای مسیر `https://setai.no/drniloo/` طراحی شده است.

## ساختار

- `index.html` — داشبورد/لندینگ پروژه SETAEI به زبان فارسی
- `styles.css` و `app.js` — طراحی RTL، موشن و اسکرول پویا
- `assets/` — تصاویر و لوگوی موقت پروژه
- `v1/` — نسخه اول وب‌سایت مشتری

## وضعیت ایندکس

فعلاً هر دو صفحه `noindex` هستند تا آدرس دقیق، شماره نظام پزشکی، مدارک حرفه‌ای، ساعات کاری و اطلاعات نهایی مشتری تأیید شوند. پس از تأیید، نسخه نهایی باید روی دامنه اصلی مشتری با ساختار کامل سئو منتشر شود.

## مسیر توسعه سئو

1. تأیید NAP و اطلاعات حرفه‌ای
2. صفحات مستقل خدمات
3. صفحات محلی واقعی برای کرج و تهران
4. FAQ، نمونه‌کار، محتوای پزشکی بررسی‌شده و داده ساختاریافته
5. Search Console، Analytics و پایش رتبه‌ها
