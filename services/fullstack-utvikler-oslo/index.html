Kan SETAEI jobbe i et eksisterende team?

Ja, både som innleid utvikler i et prosjekt og i en fast rolle. Alt arbeid dokumenteres, så andre kan bygge videre.

Tar SETAEI små oppdrag, som én integrasjon?

Ja. Mange oppdrag starter med én konkret ting, for eksempel en API-kobling eller en feil som må rettes.

Hvilke teknologier jobber SETAEI med?

React, TypeScript og JavaScript i frontend; Node.js, Python og PHP i backend; SQL-databaser som PostgreSQL og MySQL; Docker, Linux og Nginx i drift; og PyTorch, scikit-learn og LLM-er for data og AI.

Hva er forskjellen på denne siden og SaaS-siden?

Her handler det om de tekniske lagene. SaaS-siden viser hele reisen fra idé til betalende kunder, der utvikling er ett av åtte steg.
